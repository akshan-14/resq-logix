# Stage 3 ML Training Audit

This document audits the legacy synthetic data pipelines used to train Phase 4 (Route Risk) and Phase 5 (Priority Intelligence).

## Current Input Features & Labels

### Phase 4 (Route Risk / Accessibility)
- **Features**: `distance_km`, `road_condition`, `terrain_difficulty`, `rainfall_mm`, `flood_risk`, `landslide_risk`, `road_blockage`, `connectivity`, `elevation_change_m`, `bridge_condition`, `population_density`, `weather_severity`.
- **Target Label**: `accessibility_score` (0-100) and `risk_level`.
- **Label Generation**: `accessibility_score` is generated by a synthetic algebraic polynomial in `ai/generate_synthetic_data.py` (e.g., `(road_condition ** 1.2) * 1.5 + (rainfall_mm / 300 * 10) ** 1.2 * 1.2 + ...`).
- **Synthetic Features**: All of them in the training set are randomly generated NumPy arrays (`np.random.uniform`, `np.random.randint`).
- **Real Features (Inference)**: `rainfall_mm` (Open-Meteo), `distance_km` (OSRM), `elevation_change_m` (SRTM), `population_density` (WorldPop).
- **Field/BLE Features**: `road_blockage`, `bridge_condition`.

### Phase 5 (Priority Intelligence)
- **Features**: `population`, `population_density`, `vulnerable_population`, `sos_count`, `medical_emergency_count`, `injured_people`, `food_supply_days_remaining`, `water_supply_days_remaining`, `medicine_supply_days_remaining`, `shelter_demand`, `distance_to_nearest_hospital_km`, `distance_to_nearest_warehouse_km`, `accessibility_score`, `accessibility_risk`, `rainfall_mm`, `flood_risk`, `landslide_risk`, `weather_severity`, `road_blockage`, `connectivity`, `disaster_severity`, `request_age_hours`.
- **Target Label**: `priority_score` (0-100) and `priority_level`.
- **Label Generation**: `priority_score` is generated by a synthetic algebraic polynomial in `ai/generate_priority_data.py` combining `medical_urgency`, `survival_urgency`, `population_impact`, `time_urgency`, and `isolation_multiplier`.
- **Synthetic Features**: All of them in the training set are randomly generated NumPy arrays.

## Conclusion of Audit
The entire historical training apparatus is a closed-loop synthetic algebraic equation. The ML models are simply memorizing the NumPy math equations written in the generators, rather than learning physical correlations from the real world. Retraining requires entirely replacing this with physical observations.
