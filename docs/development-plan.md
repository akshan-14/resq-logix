# Development Plan

## Phase 1: Software Simulation Foundation (Current)
- Establish project structure for modular development.
- Define initial APIs and schemas.
- Implement software simulation of the mesh network.

## Phase 2: Core API & Dashboard
- Implement backend CRUD operations for SOS and Victims.
- Build basic frontend for the command dashboard.

## Phase 3: Mobile App Prototype
- Create a basic mobile UI for the victim app.
- Integrate with the simulated mesh network.

## Phase 4: Hardware Integration
- Replace the software mesh simulation with actual ESP32/BLE/LoRa hardware.
- Real device testing.

## Phase 5: AI Integration
- Connect AI module for real-time severity classification and resource allocation.
